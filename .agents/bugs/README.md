# Expedientes de bugs

Cada subdirectorio contiene el diagnóstico, plan, progreso y handoffs de un bug
real gestionado mediante `.agents/bug-cluster/`.

El Analista Técnico debe reutilizar un expediente cuando el reporte tenga la misma
causa o sea una recurrencia. Un slug nuevo debe ser breve, estable, en minúsculas
y separado por guiones. Los expedientes conservan el historial y no deben usarse
como reemplazo de las especificaciones funcionales autoritativas.
